# 최신 기보 불러오기
- 나의 아이디를 입력하고 최신 게임 불러오기를 클릭
- 내가 경기를 끝낸 가장 최신 게임의 기보를 불러올 수 있음. 분석 가능
- 이번 달 기보만 불러오기 가능

# 월별 기보 불러오기
- 내가 특정 달에 두었던 기보를 분석 가능
- 나의 아이디를 입력하고 월 정보를 입력한 후 불러오기를 클릭
- 기보가 리스트로 정렬됨
- 분석하고 싶은 기보를 클릭

# 기보 분석하기
- 기보의 처음부터 시작. 스스로 분석 가능
- 스스로 분석할 때 1점 이상 차이 나는 실수에 대해서 "실수" 표시를 남길 수 있음. 
- "실수" 표시를 전부 남겼다면 컴퓨터 분석 버튼을 클릭하여 내가 분석한 것과 컴퓨터 분석을 비교. 어떤 걸 놓쳤는지 확인
- 바로 컴퓨터 분석을 하고 싶다면 "실수" 표시 없이 그냥 컴퓨터 분석 버튼을 누르면 됨

# 실수 퍼즐
- 내 아이디의 경기를 컴퓨터 분석했을 때 실수 부분이 저장됨.
- 이후 실수 퍼즐에서 확인 가능
- 퍼즐에는 태그가 달림
- 저장된 퍼즐이 없는 경우 컴퓨터 분석이 필요하다고 알림.
